Exact SID 0x23 characterization

The previous probe used ALFID 0x14 only. That cannot reproduce 8965B4512000, whose application accepts the memory-ID request 23 15 <id> <address32> <size8>.

  • Memory ID 1LocalRAM
  • Memory ID 2DataFlash
  • WritesNone

The Sienna-specific targets include readable DataFlash, the bootloader DID-0201 buffer at FEBF2D08, and d/q observation bytes. Exact 8965B4512000, 8965H1202000, and 8965F1208000 identities also select their firmware-verified LocalRAM application-SA mirror. Unknown F181s never inherit a mirror address by prefix or family.
